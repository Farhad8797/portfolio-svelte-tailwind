# Simple Portfolio 

A modern, high-performance personal portfolio built with **SvelteKit** and **Tailwind CSS**, featuring dynamic interactive backgrounds using **Particles.js**.

---

##  Features

* **SvelteKit Powered:** Optimized for speed and incredible developer experience.
* **Tailwind Styling:** Clean, responsive UI built with utility-first CSS.
* **Particle Effects:** Interactive background particles for a premium feel.
* **Fully Responsive:** Seamless experience across mobile, tablet, and desktop.
* **Smooth Navigation:** Anchor-link scrolling with fixed header offsets.

## Tech Stack

* **Framework:** [SvelteKit](https://kit.svelte.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** [Particles.js](https://vincentgarreau.com/particles.js/)
* **Icons:** [Font Awesome](https://fontawesome.com/)
* **Image source:** [Unsplash](https://unsplash.com/)

## Getting Started

To get a local copy up and running, follow these simple steps:

### 1. Clone the repository
```bash
git clone https://github.com/Farhad8797/portfolio-svelte-tailwind.git
```
### 2. After Cloning
You need to enter the repository and install the required dependencies using the following commands:

```bash
cd portfolio-svelte-tailwind
npm install
npm run dev
```

### Notice:
To create a svelte project inside the current directory use the command: 
```bash
npx sv create .
```
